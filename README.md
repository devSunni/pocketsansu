# NEW 산수천재 (포켓산수 PWA)

1980년대 후반 한국로보콤(ROBOCOM)에서 출시한 레트로 휴대용 전자게임기 **‘NEW 산수천재(노란색 본체 버전)’**를 재현한 오프라인 웹앱(PWA)입니다.

## 주요 기능
- **레트로 하드웨어 & 흑백 세그먼트 LCD**: 일체형 손잡이가 달린 노란색 본체, 삐에로 일러스트, LCD 잔상(Ghosting) 효과, 7-세그먼트 숫자 표시
- **삐에로 공받기 게임**: 원버튼(`공받기` / `Space`) 타이밍 게임, 10점 초과 시 2구 동시 낙하, 10점 단위 가속, 최고 점수 `localStorage` 저장
- **산수 퀴즈 모드**: 덧셈(`+`), 뺄셈(`-`), 구구단(`×`)
- **계산기 모드**: `+`, `-`, `=` 기본 덧셈·뺄셈 계산기
- **피에조 부저 사운드**: Web Audio API 사각파(Square wave) 기반 레트로 효과음 및 음소거 토글

## 설치 방법
- **Android Chrome / 삼성 인터넷**: 브라우저 메뉴 → **홈 화면에 추가 / 앱 설치**
- **iPhone Safari**: 공유 버튼 → **홈 화면에 추가**
- **PC Chrome / Edge**: 주소창 오른쪽 설치 아이콘 클릭

## 구성
- `index.html`: 앱 전체 (HTML + CSS + SVG + Web Audio API + 게임 로직)
- `manifest.json`: PWA 매니페스트
- `sw.js`: 서비스 워커 (오프라인 캐시)
- `icons/icon.svg`: SVG 앱 아이콘
